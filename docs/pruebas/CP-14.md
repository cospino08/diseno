# CP-14: La sesión expira en mitad de una reserva

| Campo | Valor |
| --- | --- |
| Caso | CP-14 |
| Tipo | Disponibilidad |
| Requisito(s) | RNF-10, RF-02 |
| Caso de uso | CU-01, CU-04 |
| Pantalla | P-03 `paciente/reservar.html` → A-01 `index.html` |
| Responsable | P3 |

## Precondiciones

- `paciente1@demo.test` en la confirmación de una reserva.

## Datos usados

| Dato | Valor |
| --- | --- |
| Variante A | otra pestaña del mismo navegador pulsa **Cerrar sesión** (`supabase.auth.signOut()`) |
| Variante B | `reservar_cita` responde HTTP 401 `{ code: 'PGRST301', message: 'JWT expired' }` |

## Pasos

1. Abrir la confirmación de una reserva.
2. Variante A: en otra pestaña, cerrar sesión.
3. Variante B: pulsar **Confirmar reserva** con el token vencido.

Código de consola:

No se usa la consola: todo se hace desde la interfaz.

## Resultado esperado

Redirige al inicio de sesión con un mensaje.

## Observaciones

- **Qué prueba la ejecución 1.** Las páginas corren sin cambios, pero las respuestas de
  Supabase se reemplazan, con Chrome DevTools Protocol (`Fetch.requestPaused`), por
  respuestas con el formato exacto del contrato v1.1 (mismas columnas y mismos códigos de
  error en `message`). Así se prueba **la interfaz**: qué muestra, a dónde lleva y qué le
  pide a la base. **No** prueba la base: esa parte la cubren las pruebas de P2
  (`sql/pruebas_seguridad.sql`, 62/62 en Supabase) y la ejecución 2. El script de prueba
  usa Node y por eso **no** está en el repositorio (el proyecto no usa Node); el método
  está descrito en `docs/bitacora_ia.md`.
- Los agentes no tienen las contraseñas de las cuentas demo (las tiene el coordinador,
  fuera del repo), por eso la ejecución 2 la hace una persona.
- Corrección hecha durante la prueba: al principio, en la variante B, `index.html` veía la sesión local todavía guardada y devolvía al usuario a la reserva. Se corrigió en `auth.js` (`manejarSesionExpirada` ahora llama `signOut({ scope: 'local' })` antes de redirigir). Commit "Olvidar la sesión local cuando la base responde sesión expirada".
