# CP-01: Paciente reserva una franja libre

| Campo | Valor |
| --- | --- |
| Caso | CP-01 |
| Tipo | Funcional |
| Requisito(s) | RF-06, RF-07 |

| Responsable | P3 |

## Precondiciones

- `paciente1@demo.test` con perfil completo y sesión iniciada.
- Existe una franja futura libre de `profesional1`.

## Datos usados

| Dato | Valor |
| --- | --- |
| Cuenta | `paciente1@demo.test` (simulada en la ejecución 1) |
| Especialidad | Medicina general (`id = 1`) |
| Franjas simuladas | 3 franjas de mañana: 08:00 y 08:30 de "Dra. Laura Prueba", 09:00 de otro profesional |
| Motivo | "Control anual" |

## Pasos

1. En el inicio del paciente, pulsar **Reservar cita** (paso 1).
2. Elegir la especialidad y la fecha y pulsar **Buscar** (paso 2).
3. Pulsar una hora, por ejemplo **08:00** (paso 3).
4. Revisar el resumen, escribir el motivo y pulsar **Confirmar reserva** (paso 4).
5. Volver a **Buscar** con los mismos filtros.

Código de consola:

No se usa la consola: todo se hace desde la interfaz.

## Resultado esperado

Se crea una única cita `programada` y la franja desaparece de la búsqueda.

1. Iniciar sesión con `paciente1@demo.test` en la URL publicada.

## Observaciones

- **Qué prueba la ejecución 1.** Las páginas corren sin cambios, pero las respuestas de
  Supabase se reemplazan, con Chrome DevTools Protocol (`Fetch.requestPaused`), por
  respuestas con el formato exacto del contrato v1.1 (mismas columnas y mismos códigos de
  error en `message`). Así se prueba **la interfaz**: qué muestra, a dónde lleva y qué le
  pide a la base. **No** prueba la base: esa parte la cubren las pruebas de P2
  (`sql/pruebas_seguridad.sql`, 62/62 en Supabase) y la ejecución 2. El script de prueba
  usa Node y por eso **no** está en el repositorio (el proyecto no usa Node); el método
  está descrito en `docs/bitacora_ia.md`.
- Los agentes no tienen las contraseñas de las cuentas demo (las tiene el coordinador,
  fuera del repo), por eso la ejecución 2 la hace una persona.
- La unicidad de la cita activa por franja la garantiza el índice `uq_franja_con_cita_activa` (P2), no la interfaz.
