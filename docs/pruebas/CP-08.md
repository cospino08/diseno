# CP-08: Paciente cancela a menos de 2 h del inicio

| Campo | Valor |
| --- | --- |
| Caso | CP-08 |
| Tipo | Regla de negocio |
| Requisito(s) | RF-12 |
| Caso de uso | CU-05 |
| Pantalla | P-04 `paciente/mis-citas.html` |
| Responsable | P3 |

## Precondiciones

- `paciente1@demo.test` con una cita programada que empieza en menos de 2 horas.

## Datos usados

| Dato | Valor |
| --- | --- |
| Cita simulada | hoy 23:00, `programada`, con `puede_cancelar = true` (para forzar el intento) |
| Respuesta simulada de `cancelar_cita` | `{ code: 'P0001', message: 'FUERA_DE_PLAZO' }` |

## Pasos

1. Abrir **Mis citas**.
2. Comprobar que una cita a menos de 2 h **no** muestra el botón "Cancelar cita" (usa `puede_cancelar` de `mis_citas`).
3. Forzar el intento: pulsar "Cancelar cita" y confirmar en el diálogo cuando la base responde `FUERA_DE_PLAZO`.
4. Ejecución 2: llamar `cancelar_cita` desde la consola.

Código de consola:

```js
const { supabase } = await import('./assets/js/datos/cliente.js');  // ajustar la ruta relativa
const { error } = await supabase.rpc('cancelar_cita', { p_cita_id: <id de la cita> });
console.log(error?.message);   // esperado: 'FUERA_DE_PLAZO'
```

## Resultado esperado

`FUERA_DE_PLAZO`; la cita no cambia.

## Observaciones

- **Qué prueba la ejecución 1.** Las páginas corren sin cambios, pero las respuestas de
  Supabase se reemplazan, con Chrome DevTools Protocol (`Fetch.requestPaused`), por
  respuestas con el formato exacto del contrato v1.1 (mismas columnas y mismos códigos de
  error en `message`). Así se prueba **la interfaz**: qué muestra, a dónde lleva y qué le
  pide a la base. **No** prueba la base: esa parte la cubren las pruebas de P2
  (`sql/pruebas_seguridad.sql`, 62/62 en Supabase) y la ejecución 2. El script de prueba
  usa Node y por eso **no** está en el repositorio (el proyecto no usa Node); el método
  está descrito en `docs/bitacora_ia.md`.
- Los agentes no tienen las contraseñas de las cuentas demo (las tiene el coordinador,
  fuera del repo), por eso la ejecución 2 la hace una persona.
- Ocultar el botón es usabilidad, no seguridad: la regla de 2 horas la valida `cancelar_cita` en la base.
